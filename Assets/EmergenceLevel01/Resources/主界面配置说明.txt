主界面与暂停窗口配置

打开 Assets/Scenes/MainMenu.unity 后运行即可预览主界面。
MainMenu 已加入 Build Settings 第一位，原有关卡顺序保留。
界面由 GameMenuUI 在运行时创建，因此编辑模式下场景中仅有摄像机。

配置资源：Assets/EmergenceLevel01/Resources/GameMenuConfig.asset
在 Inspector 中可修改标题、副标题、开始关卡、字体、配色、角色素材、位置、缩放、旋转、开始淡入淡出时间和暂停快捷键。
角色素材复用已有机器人身体、表情头像和博士原图。
默认开始关卡为 Level01_InitialLab；开始游戏会重置本次会话的情感解锁进度。

游戏内点击右上角齿轮或按 Escape 打开暂停窗口。
暂停会停止游戏时间、游戏音效、玩家操作和剧情播放计时；继续游戏恢复暂停前状态。
退出游戏：打包版本关闭程序；Unity 编辑器内停止 Play。
暂停窗口自动出现在各关卡，无需逐个场景挂载。

验证：独立 Unity 测试工程中编译并通过 19 项运行检查。
预览和检查报告：项目 Logs/GameMenu 文件夹。
开始过渡：黑幕淡入 → 黑屏等待 1 秒 → “接入信号”淡入 0.8 秒 → 停留 2 秒 → 文字淡出 1 秒 → 加载第一关并揭开黑幕。
在 GameMenuConfig 的“开始游戏 · 接入信号过渡”配置文字和时长；Start Fade Seconds 控制两端黑幕淡变时长。留空文字可跳过字幕。

游戏通关交互：将 Prefabs/GameCompletionInteraction.prefab 拖到最终关卡的终点位置，或在已有物体上添加 GameCompletionInteraction。
该预制体只提供交互逻辑，可放在现有终端、门等美术物体旁；不要在同一位置保留普通 LevelExitInteraction，以免交互目标冲突。
玩家靠近后按 F；仍需收集完当前场景所有情感碎片。
默认：黑幕淡入 0.8 秒 → 等待 1 秒 → “机械情感”换行“完”淡入 1 秒 → 完全显示 2 秒 → 返回主界面。
组件 Inspector 可改交互半径、字幕、字体字号、各阶段时长和返回的主界面名称。

自动切换情感区域：Prefabs/EmotionSwitchTrigger.prefab。
拖入关卡后调整 Box Collider 2D 的 Size/Offset 或 Edit Collider 设置范围，保持 Is Trigger 开启。
Target Emotion 指定目标情感（Joy 开心、Anger 愤怒、Sadness 悲伤、Courage 勇气、Guardian 守护、Memory 怀念、Blank 无情感）。
Unlock Target Emotion 默认开启，触发时一并解锁；关闭则目标未解锁时不执行，也不消耗单次触发。
Trigger Once 默认开启，仅在当前场景实例成功触发一次；关闭后离开并再次进入可重复触发。重载场景后重置。
玩家进入范围后立即切换，无需按键或蓄力；NPC 不受影响。暂停、剧情阻止输入、切场景或触发器时停时不会执行；仍在区域内时会在限制解除后重试。
On Triggered 可绑定成功后的事件。外部代码可调用 TryTrigger(player)，ResetTrigger() 可重置使用状态。

暂停面板新增“重置关卡”，与 R 键使用同一重置流程：播放黑幕、恢复最后存档点，并保留当前场景已收集的情感碎片。该保留仅用于本次场景重置，不是跨游戏存档。
NPC 即使被增强悲伤时停，仍能通过 E 接收玩家传递的情感；路线移动继续遵循时停规则。
危险区域持续检查重叠角色，NPC 静止或休眠时失去增强勇气也会受伤。
怀念共鸣状态在读取时刷新。已删除进入怀念情感时的泛白；回忆剧情切场景的白色淡入淡出保留。

移动端适配（Android / iOS 横屏）
手机自动显示触控；电脑默认保持键鼠操作。在 GameMenuConfig 勾选 Mobile Preview 可在 Game 视图预览触控。
左侧 ◀ ▶ 移动；右侧跳跃（按住跳更高）、交互、传递（长按）；底部选择六种已解锁情感。
剧情非自动播放时显示“继续对话”；点击场景选择/放置拼装件，“取消选择”清空选中。
可配置 Mobile Button Scale、Mobile Button Opacity、Mobile Target Frame Rate。按钮与对话框避开安全区；暂停、切场景、切后台会清理触控输入。
中文字体使用 Fonts/NotoSansCJKsc-Regular.otf，授权见同目录 OFL.txt；GameMenuConfig.Font 可替换为其他有授权的中文字体。
当前编辑器只有 Windows/WebGL 支持模块。Android 需 Unity Hub 安装对应版本 Android Build Support、SDK/NDK/OpenJDK；iOS 需 iOS Build Support，并在 macOS/Xcode 上完成签名与真机安装。
Android 正式发布配置建议在安装模块后选择 IL2CPP/ARM64，配置包名和签名；iOS 配置 Bundle Identifier、签名团队。此轮不包含签名、商店发布或真机性能结论。
