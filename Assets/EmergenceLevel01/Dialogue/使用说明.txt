剧情对话系统

使用方式
1. 第一关 Level01_InitialLab 进入运行时自动播放博士开场。文字逐字出现；未显示完时按 C 立即显示全文，显示完后再按 C 前进一句，最后一句再按 C 关闭。
2. 配置目录 Assets/EmergenceLevel01/Dialogue。选择 .asset，在 Inspector 的 Lines 中编辑 Speaker、Text、Minimum Display Seconds 和 Cue；Speaker 为空时不显示姓名。
3. 新建资源：Project 右键 > Create > Emergence > Dialogue Sequence。
4. Block Player Input 默认开启：禁止移动、跳跃、Q 情绪切换、愤怒破坏和鼠标合成操作；保留重力。关闭该选项可制作边走边说的对话。
5. Typewriter 控制是否逐字显示。剧情资源 Characters Per Second 默认为30字/秒；单句同名字段为0时继承，可设不同速度。
6. 同段文本内插入 <pause=秒数> 配置句间或句中停顿，例如：伊……<pause=1>这是我的代号吗？<pause=0.5>我明白了。标签不显示，可以使用多个不同停顿。
7. 按 C 补全时会跳过本段所有剩余停顿。Minimum Display Seconds 仍是从本段开始算起的最短显示时间，不代替句间停顿。停顿和打字使用不受 Time.timeScale 影响的时间。
8. 演出备注保存在 Staging Notes，不显示给玩家。

代码调用（using Emergence.Level01）
DialogueDirector.Instance.TryPlay(sequence); // 返回是否成功；正在对话时不会覆盖
DialogueDirector.Instance.Advance();         // 推进一句；受最小显示时间限制
DialogueDirector.Instance.Stop();            // 取消；不会触发正常完成事件

接口与事件
Director.Play(DialogueSequence) 是可在 Inspector UnityEvent 中选择的 void 接口。
Director.Started / LineChanged / Finished / Cancelled 为 C# 事件。
LineChanged(sequence, lineIndex) 可读取 sequence.lines[lineIndex].cue 来触发说话、转身、换表情等动作。
Director 的 On Started / On Finished 可在 Inspector 挂接事件。

触发区域与关卡事件
在场景物体上挂 DialogueTrigger，指定 Sequence。
调用 Trigger()（可绑定 UnityEvent）或 TryTrigger()（返回成功与否）。
需要靠近触发时：添加 Collider2D 并勾选 Is Trigger，开启 Trigger On Enter；玩家必须有 Rigidbody2D 和 Collider2D。
Play Once 默认开启；正常完成后只播放一次。中途取消则允许重新触发。
On Completed 只在该触发器发起的对话正常结束时调用，可挂接开舱、角色走位或下一段剧情。

验证
Tools > Emergence > Verify Dialogue System
报告 Logs/Dialogue/verification.txt，画面 Logs/Dialogue/preview.png。
重新安装菜单 Setup Dialogue System 不覆盖已有剧情资源，避免清除手动改过的文本。

CompleteCurrentLine() 可立即补全当前句。IsRevealing / VisibleText / FullText 可供外部UI查询；Advance() 在打字中只补全，不同时跳到下一句。
